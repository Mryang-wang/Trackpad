# 蓝牙触控板测试版

手机充当 BLE 中央设备，Mac 接收端发布 GATT 服务。两端在本机保留连接码，每次重新连线都使用新的挑战值。遥控通过 BLE 传输。手机停留在测试 App 时会自动重连，重新打开 App 也会尝试重连。手动点「断开」后，需要再次点「连接」。

## 安装和连接

1. 打开「蓝牙触控板接收端」，允许蓝牙。接收端提示未授权时，点「授权控制鼠标」，到「系统设置 → 隐私与安全性 → 辅助功能」开启同名条目。
2. 在支持 BLE 的 Android 6.0 或更新版本上安装 `Build/BluetoothTrackpad/Trackpad-Test.apk`。首次连接时，Android 12 及以后选择允许访问「附近的设备」。Android 11 及以前的蓝牙扫描需要位置权限，部分系统还需要开启定位。
3. 首次在手机测试 App 点右上角的设置，输入 Mac 窗口上的 6 位连接码，再点「连接」。连上后即可拔下安装用的 USB 线。

手机界面支持左右两种横握方向。连上后，横屏铺满触控区，右上角保留设置。需要手机的系统栏时，从屏幕边缘向内滑动。

关闭 Mac 接收端的窗口后，触控板仍可使用。点 Dock 中的接收端图标可再次打开窗口。需要断开接收端时，从 Dock 菜单选「退出」。

## 四项实测

| 操作 | 观察结果 |
| --- | --- |
| 在触控区单指向四个方向滑动 | Mac 光标跟着移动，抬手后停下。 |
| 对着 Mac 上一个可以安全点击的控件，单指轻点 | Mac 触发左键。双指同时轻点触发右键。 |
| 将 Mac 光标移到长网页、文本或 Finder 列表，再用双指上下滑动 | Mac 内容滚动，光标留在原处。 |
| 将 Mac 光标移到文字起点或窗口标题栏，再三指滑动 | Mac 按住左键拖移。抬起任一手指时释放左键。 |
| Mac 有多个桌面或全屏 App 时，用四指左右滑动 | 切换相邻空间。Mac 的「调度中心」键盘快捷键需启用 Control 加左右箭头。 |
| 在手机上关闭蓝牙，等 Mac 显示等待重连，再打开手机蓝牙并回到测试 App | 等两边自动显示「已连接」，再验证光标和滚动。 |

Mac 窗口里的计数表示接收端已向系统提交的事件。该版本用于已登录的 Mac 桌面。

小米系统的「三指下滑截屏」和「三指长按局部截屏」可能抢先处理多指触摸。可在手机的「设置 → 更多设置 → 快捷手势」关闭相关截屏手势后再试。

## 本地构建

需要 macOS 13 或更新版本、Xcode Command Line Tools、JDK 11 或更新版本、Android SDK Platform 35 和 Build-Tools 35。可将 `ANDROID_PLATFORM_JAR` 和 `ANDROID_BUILD_TOOLS` 指向本地 SDK，或将对应官方 SDK 压缩包解到 `Build/BluetoothTrackpadToolchain` 后运行：

```sh
./Experiments/BluetoothTrackpad/build.sh
```

输出位于 `Build/BluetoothTrackpad`。Mac 接收端优先复用项目已有的本机签名证书，以保留本机更新身份。测试 APK 使用输出目录下的本地测试签名密钥。
