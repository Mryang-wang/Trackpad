# Trackpad 控制台测试版

手机端为 0.3.6，Mac 接收端为 0.4.2。当前 Mac 安装位置为 `~/Applications/Trackpad 控制台接收端.app`，打开后在菜单栏常驻，可从菜单栏显示连接窗口或退出。Dock 中不显示图标，已授权时启动不自动弹窗。稳定版压缩备份位于 `Trackpad/Stable`。窗口红叉只关闭窗口，接收端仍会在后台运行。

## 安装和使用

1. 打开「应用程序」中的「Trackpad 控制台接收端」，首次允许蓝牙，并在 Mac「系统设置 → 隐私与安全性 → 辅助功能」启用它。需要查看连接码时，在菜单栏点接收端图标并选择「显示连接窗口」。0.4.0 起使用固定本机证书签名，授权后重启和正常更新均可沿用当前权限。
2. 在 Android 安装 `Trackpad-Console-0.3.6.apk`，打开「Trackpad 控制台测试」。首次使用时，在右上角蓝牙设置输入测试接收端显示的六位码，并允许访问附近设备。
3. 连上后点右上角菜单里的「Mac 控制台」。首页为应用图标网格，运行中的应用在前，其余应用在后，两组各按首字母排列，中文按拼音与英文混排。搜索支持忽略大小写、全角字母、中文名称、拼音和首字母，例如 `AQY` 可找爱奇艺，`bdwp` 可找百度网盘。轻点图标打开或切换，手机随后核对 Mac 前台状态并显示结果。长按打开操作菜单，包含打开／切换、退出应用、应用详情和返回。未运行应用的退出按钮为灰色。若有保存提示，请在 Mac 上处理。
4. 长按 ChatGPT / Codex 图标后进入「应用详情」，可选择听写、发送草稿、停止回复和新建对话。听写、发送、停止回复时，请先在 Mac 前台打开 Codex 对话。侧边栏可保持收起。听写使用 Mac 上 Codex 当前选用的麦克风，结果留在草稿。
5. 点左上角「触控板」回到整屏触控区。应用图标放大显示，卡片只保留一行名称。图标按可见区域压缩传输并缓存，失败时重试一次，未获得图标时显示应用名称首字。操作按钮优先于图标加载。打开或退出应用后只查询该应用的运行状态。完整列表首次同步完成后会原子写入手机的持久缓存，下次进入立即显示缓存，只核对列表版本并读取运行状态。Mac 重启和蓝牙重连后会重新验证应用编号。安装、卸载、更新应用导致列表变化时会重新同步，手动点「刷新」也可重新读取整个列表。运行中的应用使用淡青色光晕边框。

## 构建

需要 Xcode Command Line Tools、JDK 11 或更高版本、Android SDK Platform 35 和 Build-Tools 35。首次在此 Mac 构建前运行 `./setup-signing.sh`，创建并保存固定签名身份。私钥保存在登录钥匙串，`macos/SigningIdentity.sha1` 只记录公开证书指纹。后续构建复用此身份，缺失时会中止。通过环境变量 `ANDROID_PLATFORM_JAR` 和 `ANDROID_BUILD_TOOLS` 指定 SDK 路径，再运行此目录的 `./build.sh`。仅构建手机端时运行 `./build.sh --android-only`，仅构建 Mac 接收端时运行 `./build.sh --mac-only`。产物输出到 `Console/Build`，测试签名与稳定版分开。

Mac 构建产物名为 `Trackpad Console Host.app`。构建后运行 `./install-host.sh`，会校验固定签名、退出旧进程并替换当前安装，保留权限和连接码。当前版本的安装压缩包为 `Console/Build/Trackpad-Console-Host-0.4.2.zip`。

登录自启动通过 `./enable-login.sh` 配置。它在当前用户的 `~/Library/LaunchAgents/local.trackpad.console.host.login.plist` 写入登录任务，使用已安装的接收端及 `--background` 参数。登录后只在菜单栏后台运行，权限提示也不会自动打开连接窗口。`./install-host.sh` 会在更新已启用的登录任务时通过该任务重新启动接收端。
